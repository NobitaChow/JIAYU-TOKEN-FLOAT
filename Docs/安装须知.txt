JIAYU STUDIO · 用量悬浮窗 0.1.0

1. 如果正在运行旧版，请先从菜单栏退出。
2. 将左侧 JIAYU Token Float 0.1.0 拖入右侧 Applications。
3. 从「应用程序」打开应用，随后弹出安装磁盘。

适用于 macOS 13 及以上、Apple Silicon（M 系列）。
首次扫描本地日志可能需要数分钟，扫描完成前显示部分统计。
按住悬浮窗左侧四点拖动，单击数值展开，在设置中自定义折叠字段。
详细使用方法与计量口径请阅读同盘「使用说明书.pdf」。

应用不联网、不读取钥匙串或认证文件，无需录屏、辅助功能或管理员权限。
金额是 API 等价估算，不是订阅扣费或账户账单。
本包采用本地 ad-hoc 签名，尚未获得 Apple 开发者公证。

源码及后续版本：https://github.com/NobitaChow/jiayu-token-float
